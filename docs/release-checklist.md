# Bichoku release checklist (Juan's steps)

The build plans end at a release candidate; these steps need Juan's accounts or approval. The portfolio's `release-game` skill will run them with him. In order:

0. **Done (2026-11-25):** the GitHub org `Churrinche-Games` exists; `Churrinche-Games/bichoku` and `Churrinche-Games/game-kit` are pushed (private; commits use the GitHub noreply address); the site `https://churrinche-games.github.io` is live with the privacy policy at `https://churrinche-games.github.io/bichoku/privacy/` (contact: the site repo's issues until the feedback email exists). Still yours: upload the org picture (`game-kit/docs/brand/churrinche-500.png`) and set the org's description and website (`https://churrinche-games.github.io`) in the org settings.
1. **Done (2026-11-25):** the feedback email `churrinchegames@gmail.com` (in `game_info.cfg`, the privacy policy and the site); the Google Play developer account (personal). Developer-page icon: `game-kit/docs/brand/churrinche-512.png`.
2. **Upload key:** create the keystore outside the repo (`keytool -genkeypair …`), keep it and its passwords out of git; enroll in Play App Signing.
3. **Repo:** push to `github.com/churrinche-games/bichoku`; (the privacy policy is already on the org site); check the About screen's source link and the Feedback screen's issues link open.
4. **Play Console:** create the app (`com.churrinche.bichoku`, free); listing from `docs/store/listing.es-419.md` and `listing.en-US.md`; icon, feature graphic and screenshots from `tools/store.sh` (`build/store/`: `icon-512.png`, `feature-<lang>.png`, `screenshots/<lang>/` — phone 1080×1920 (also for the tablet slots) and 1080×2160, tablet 1536×2048, and the web build's 1280×720); content rating questionnaire; target audience 13+; Data safety: no data collected or shared; privacy policy URL.
5. **Closed test:** set `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `_USER` and `_PASSWORD` in your shell (the upload key; never in the repo) and run `tools/export.sh aab-release`; upload `build/android/bichoku.aab` to the closed track (the plain `aab` mode is debug-signed, and Play rejects it); invite the standing tester group (≥12 testers opted in for 14 continuous days).
6. **Production:** promote after the 14 days and any fixes from the testers' feedback. Re-check Play's payments policy (no donation links in the Play build).
7. **itch.io:** donation links in `game_info.cfg` `[support] links`; export with `tools/export.sh web` (upload `build/bichoku-web.zip`, "This file will be played in the browser") and `tools/export.sh itch-apk` (`build/itch/bichoku.apk`; needs the Java SDK path, JDK 17, in Godot's Editor Settings); create the page (free, pay what you want); upload with butler.
8. **Make the repo public** if it isn't yet.
